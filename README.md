## 1. Project Overview

**MERIDIAN** is an enterprise B2B digital platform demonstration created to showcase what modern manufacturing companies, wholesale suppliers, and industrial component fabricators need in a high-performance web experience.

The platform provides a complete corporate industrial presence:
- 11 dedicated, cleanly structured pages and routes.
- **Strictly ZERO `.html` extensions** anywhere in URLs or file architecture.
- Atmospheric, authentic industrial photographic hero backgrounds on every route.
- Deep graphite/navy gradient scrims with crisp drop-shadowed white typography.
- Solid, high-contrast, prominent CTA buttons with zero transparency issues.
- A distinctive **Industrial Command Console Navigation** that opens a floating mechanical control matrix with numbered subsystem tiles.

---

## 2. Dedicated Pages & Routes

1. **Home (`/`)**: Industrial hero *"Manufacturing Excellence. Supply You Can Depend On."*, 4 business capacity metrics, company intro, featured products, capabilities preview, industries served, and wholesale CTA.
2. **About Us (`/about`)**: 30-year heritage story, vision & mission, 4 industrial philosophy pillars, executive leadership profiles, and in-line metrology showcase.
3. **Manufacturing (`/manufacturing`)**: 6 integrated production workcenters, CNC machinery specs, and the mandatory 7-stage manufacturing process workflow.
4. **Products (`/products`)**: 10 B2B industrial products across 8 categories, live keyword search, category filter pills, sorting options, and technical detail modal.
5. **Industries We Serve (`/industries`)**: 10 commercial sectors (Construction, Automotive, Electrical, Retail, Packaging, Furniture, Textiles, Food Processing, OEMs, Institutional), key supplied products, and operational benefits.
6. **Wholesale & Distribution (`/wholesale`)**: Bulk product availability, distributor partnership benefits, factory credit lines, and on-page dealership application form with code generator (`MER-DIS-2026-XXXX`).
7. **Quality Control (`/quality`)**: 5-stage comprehensive quality protocol (Spectrometry, 3D CMM, NDT, Hydrostatic, MTC audit), and an audited Mill Test Certificate (EN 10204 3.1) simulation.
8. **Infrastructure (`/infrastructure`)**: 180,000 sq. ft. campus showcase, 4 specialized infrastructure facilities (Heavy Machining, Laser Fabrication, Metrology Lab, Automated High-Bay Warehouse).
9. **Resources (`/resources`)**: 8 downloadable technical documents & data sheets (TDS), live search, category filters, simulated download triggers, and FAQ accordion.
10. **Request a Quote (`/quote`)**: Enterprise B2B requisition form collecting company, contact, volume, units, delivery location, CAD file upload, and ticket generator (`MER-RFQ-2026-XXXX`).
11. **Contact Us (`/contact`)**: Plant location address, direct phone/email channels, operating hours, interactive inquiry form with ticket generator (`MER-ENQ-2026-XXXX`), and WhatsApp link.

## 3. Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom industrial color scales (`graphite-900`, `industrial-700`, `copper-600`)
- **Icons:** Lucide React
- **Typography:** Inter (Sans-serif) & JetBrains Mono (Technical codes)
- **State Management:** React Context API (`RfqContext`)

## 4. Local Development

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/ilath9198-wq/008-manufacturing-wholesale.git

# Navigate to project directory
cd 008-manufacturing-wholesale

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 5. Production Build

To verify and create a production build:

```bash
npm run build
npm start
```
